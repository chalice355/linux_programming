# UNIX 운영체제에 대하여 조사하시오.
## 1. 개요
- UNIX는 1969년 미국 벨 연구소의 켄 톰프슨과 데니스 리치가 개발한 운영체제로, 이후 C언어로 재작성되면서 이식성이 크게 향상.
- 대학 및 연구기관을 중심으로 확산되며 이후 수많은 파생 운영체제(Linux, BSD, macOS 등)의 뿌리가 됨.
- 주요 특징으로는 멀티태스킹, 계층적 파일 시스템, 이식성, 강력한 셀 환경 등이 있음.

## Linux, Windows, macOS 를 비교 설명하시오.
| 항목 | Linux | Windows | macOS |
| --- | --- | --- | --- |
| 개발사 | 리누스 토발스 | Microsoft | Apple |
| 커널 기반 | 리눅스 커널 | Windows NT 커널 | Darwin |
| 라이선스 | 오픈소스 | 사용, 유료 라이선스 | Apple 하드웨어 번들 |
| 공개 여부 | 공개(오픈소스) | 비공개 | 커널 일부(Darwin)만 공개 |
| 사용자 인터페이스 | CLI 중심 | GUI 중심, 사용자 편의성 | GUI 중심, 통일된 디자인 |
| 하드웨어 호환성 | 광범위한 하드웨어 지원(서버, 임베디드 포함) | PC 및 주변기기 | Apple 자체 하드웨어 환경 최적화 |

## 우분투(Ubuntu) 리눅스에 대하여 조사하시오.
- Debian 기반의 리눅스 배포판으로, "인간성(Humanity)"을 뜻하는 아프리카 반투어에서 유래.
- 주요 특징 : 사용 편의성, 정기적인 업데이트 주기, 무료 및 오픈소스, 다양한 배포판, 활성화 된 커뮤니티 및 문서 등이 있음.
- 활용 분야 : 개인용 데스크톱 OS, 웹/클라우드 서버, 개발 및 테스트 환경, IoT 및 임베디드 기기

## 임베디드 시스템용 운영체제로 리눅스가 적합한 이유를 설명하시오.
- 오픈소스 및 무료 라이선스로 비용 없이 자유롭게 수정 및 배포가 가능하여 제품 원가 절감에 직접적인 기여.
- 리눅스 커널은 뛰어난 이식성으로 다양한 프로세서 아키텍처를 지원하여, 소형 저전력 임베디드 보드부터 고성능 산업용 장비까지 최적화가 용이.
- 불필요한 모듈과 드라이버를 제거하고 필요한 기능만 선택적으로 컴파일 할 수 있어 커널 및 시스템의 경량화 가능.
- 오랜 기간 서버 환경에서 검증된 커널로, 장시간 무중단 동작이 요구되는 산업용 임베디드 기기에 적합한 높은 안정성.

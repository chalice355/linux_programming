# 셸과 커널을 구분하여 자세히 설명하시오.
| 구분 | 커널 | 셸 |
| --- | --- | --- |
| 위치 | 운영체제의 가장 안쪽, 하드웨어 위 | 커널을 감싸는 바로 바깥층 계층 |
| 역할 | CPU, 메모리, 디스크 등 하드웨어를 직접 관리하고, 명령어를 실제로 실행하며 프로세스를 관리 | 사용자가 입력한 명령어를 받아 해석하고, 그 실행을 커널에게 요청한 뒤 그 결과를 사용자에게 출력 |
| 접근 | 사용자 직접 조작 불가 | 사용자가 직접 사용하는 인터페이스 | 

# 프롬프트 문자열에서 문자 ~의 의미를 조사하라.
* 틸트(~)는 리눅스/유닉스 셸에서 현재 로그인한 사용자의 홈 디렉터리를 나타내는 특수 기호.
* 현재 디렉터리가 /home/tmp라면, 프롬프트의 admin@linux:~$에서 틸트는 /home/tmp를 가리킴.
* cd ~ 또는 그냥 cd만 입력하면 홈 디렉터리로 이동.

# sh, bash, zsh 셸의 차이를 자세히 조사하시오.
| 항목 | sh | bash | zsh |
| --- | --- | --- | --- |
| 개발/연도 | 1977년, 스티브 본 | 1989년, 브라이언 폭스 | 1990, 폴 팔스타드 |
| 위치 | 유닉스 원조 기본 셸 | 리눅스 표준 셸, sh를 계승 및 확장 | bash와 tcsh의 장점을 결합 |
| 호환성 | 최소 기능 셸 | sh와 대체로 하위 호환 | bash와 대체로 호환 |
| 대표 기능 | 기본적인 스크립트 실행 기능만 제공 | 명령어 히스토리, 탭 자동완성, 별칭, 작업 제어, 배열 등 | bash보다 더 강력한 자동완성, 테마 및 플러그인 지원, 철자 자동 교정 등 |
| 대표 사용처 | 시스템 스크립트에서 최소 기능으로 널리 사용 | 대부분의 리눅스 배포판 기본 셸 | macOS Catalina 이후 기본 셸 |

# 셸 스크립트에 대하여 자세히 조사하시오.
* 셸 스크립트란, 셸에서 실행할 명령어들을 한 줄씩 순서대로 파일에 기록해두고, 그 파일을 한 번에 실행함으로써 여러 작업을 자동화하는 텍스트 파일.
* 매번 손으로 입력하는 대화형 방식과 달리, 반복적인 작업을 자동화 가능
* 조건문, 반복문, 변수, 함수 등 프로그래밍 요소를 사용 가능
* 실행 권한을 부여한 뒤에 ./스크립트이름.sh 형태로 실행 가능

# Windows에서 사용하는 CLI 방식의 셸의 종류를 조사하라.

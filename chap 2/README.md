# 리눅스 명령어가 무엇인지 설명하시오. 또, 실제 명령어의 정체는 무엇인가?
* 명령어란, 운영체제(셸)에게 특정 작업을 수행하도록 지시하는 단어.
* 사용자가 프롬프트에 명령어를 입력하면, 셸이 이를 해석하여 커널에게 실행을 요청.

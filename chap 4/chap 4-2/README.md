# ls 명령어의 4가지 옵션 -a, -l, -F, --help을 설명하고 각각 실행 예를 첨부하시오.
| 명령어 | 설명 | 실행 예 |
| --- | --- | --- |
| -a | .으로 시작하는 숨김파일까지 모두 출력 |
| -l | 파일 타입, 권한, 링크 수, 소유자, 그룹, 크기, 수정 시각, 이름 등의 상세정보 출력 |
| -F | 파일 이름 뒤에 종류를 나타내는 기호를 붙여 출력 | 
| --help | ls 명령어의 사용법과 사용 가능한 모든 옵션 목록 출력 |

# 경로확장 문자 *, ?의 의미를 설명하고 각각 실행 예를 첨부하시오.
| 명령어 | 설명 | 실행 예 |
| --- | --- | --- |
| * | 임의의 문자열을 의미 | 
| ? | 임의의 한 문자를 의미 |
